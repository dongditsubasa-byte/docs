## 接口概述

返回指定城市**当前时刻**的融合天气实况，含气温、湿度、风力、降水、能见度、天气现象等。

| 项目 | 说明 |
|------|------|
| 覆盖范围 | 中国大陆主要城市（见[城市列表](/zh/reference/location-codes)） |
| 更新频率 | 约每 15 分钟更新一次 |
| 时区 | 业务时间多为北京时间；场站预报库内为 UTC，响应同时提供本地时间 |
| 鉴权 | 请求头 `X-API-Key`；需开通对应模块权限 |

### 相关参考

- [天气现象代码](/zh/reference/weather-codes)
- [风速等级](/zh/reference/wind-scale)
- [城市列表](/zh/reference/location-codes)

## 请求

```
GET /v1/weather/condition
GET /weather/condition
```

### 查询参数

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `city_uid` | integer | 四选一 | 内部城市 ID，优先级最高 |
| `city_code` | string | 四选一 | GB2260 行政区划代码，如 `110000` |
| `city_name` | string | 四选一 | 城市名称，如 `北京市` |
| `lat` | number | 与 lon 成对 | 纬度 -90~90 |
| `lon` | number | 与 lat 成对 | 经度 -180~180 |
| `format` | string | 否 | 响应格式：`json`（默认）/`csv`/`tsv`/`xml`/`yaml` |

### 请求示例

```bash
curl -s "https://api.sunnymeteo.com/v1/weather/condition?city_name=北京市" \
  -H "X-API-Key: YOUR_KEY"
```

## 响应

### JSON 结构

```json
{
  "city": {
    "city_uid": 11000001,
    "city_code": "110000",
    "city_name": "北京市",
    "parent_city_name": "北京市",
    "parent_province_name": "北京市"
  },
  "condition": {
    "update_time": "2026-08-24T07:00:00+08:00",
    "weather_code": 1,
    "weather_cn": "晴",
    "temp": 28.5,
    "humidity": 45,
    "wind_speed": 3.2,
    "wind_level": 2,
    "precip_1h": 0.0,
    "vis": 10000
  }
}
```

### `city` 字段

| 字段英文名 | 类型 | 单位 | 中文名 |
|------------|------|------|--------|
| `city_uid` | integer | — | 内部城市 ID |
| `city_code` | string | — | GB2260 代码 |
| `city_name` | string | — | 城市名称 |
| `parent_city_name` | string | — | 上级市/区名称 |
| `parent_province_name` | string | — | 所属省份 |

### `condition` 字段

| 字段英文名 | 类型 | 单位 | 中文名 |
|------------|------|------|--------|
| `update_time` | string | ISO8601 | 数据源更新时间 |
| `weather_code` | integer | — | 天气现象代码（见参考文档） |
| `weather_cn` | string | — | 天气现象中文名 |
| `temp` | number | ℃ | 气温 |
| `dewpoint` | number | ℃ | 露点温度 |
| `real_feel` | number | ℃ | 体感温度 |
| `humidity` | number | % | 相对湿度 |
| `pressure` | number | hPa | 本站气压 |
| `mlsp` | number | hPa | 海平面气压 |
| `wind_dir` | string | — | 风向文字 |
| `wind_degrees` | number | ° | 风向角度（0–360） |
| `wind_speed` | number | m/s | 风速 |
| `wind_level` | number | 级 | 蒲福风力等级 |
| `gust_speed` | number | m/s | 阵风风速 |
| `gust_level` | number | 级 | 阵风等级 |
| `precip_1h` | number | mm | 1 小时降水量 |
| `snow_1h` | number | mm | 1 小时降雪量 |
| `cloud` | number | % | 总云量 |
| `vis` | number | m | 能见度 |
| `uvi` | number | — | 紫外线指数 |
| `solar` | number | W/m² | 太阳辐射 |
