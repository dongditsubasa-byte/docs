## 接口概述

返回展示时区当天 0 点起未来 15 天的逐小时气象预报；光伏场站附带 pvlib 估算功率。

| 项目 | 说明 |
|------|------|
| 覆盖范围 | 有效光伏/风电场站 |
| 更新频率 | 北京时间每日 06:00、19:00 各更新一次（past_days=1 + forecast_days=16） |
| 时区 | 业务时间多为北京时间；场站预报库内为 UTC，响应同时提供本地时间 |
| 鉴权 | 请求头 `X-API-Key`；需开通对应模块权限 |

## 请求

```
GET /v1/power/hourly
GET /power/hourly
```

### 查询参数

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `station_alias` | string | 三选一 | 场站内部别名（优先），如 `PVSDCW` |
| `station_name` | string | 三选一 | 场站名称 |
| `lat` | number | 与 lon 成对 | 纬度；匹配最近有效场站 |
| `lon` | number | 与 lat 成对 | 经度 |
| `format` | string | 否 | `json`/`csv`/`tsv`/`xml`/`yaml` |

## 响应

结构：`{ station, timezone, display_tz, count, points[] }`。
