## 接口概述

按起始时间查询中国地震台网目录记录。

| 项目 | 说明 |
|------|------|
| 覆盖范围 | 中国及周边；历史窗口约 7 天（接口可查范围） |
| 更新频率 | 约每 5 分钟更新 |
| 时区 | 业务时间多为北京时间；场站预报库内为 UTC，响应同时提供本地时间 |
| 鉴权 | 请求头 `X-API-Key`；需开通对应模块权限 |

### 相关参考

- [状态码](/zh/api-guide#状态码与错误)

## 请求

```
GET /v1/disasters/earthquake/cn
GET /disasters/earthquake/cn
```

### 查询参数

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `startfrom` | integer | **是** | Unix 时间戳（秒） |

## 响应字段（`earthquakes.items[]`）

| 字段英文名 | 类型 | 单位 | 中文名 |
|------------|------|------|--------|
| `ceic_id` | string | — | 台网唯一 ID |
| `event_time` | string | ISO8601 | 发震时刻（北京时间） |
| `latitude` | number | ° | 纬度 |
| `longitude` | number | ° | 经度 |
| `depth_km` | number | km | 震源深度 |
| `magnitude` | number | M | 震级 |
| `location` | string | — | 参考地名 |
| `city_uid` | integer | — | 最近匹配城市 ID |
| `city_name` | string | — | 匹配城市名 |
