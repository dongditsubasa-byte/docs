## 接口概述

返回城市当前 AQI 及主要污染物浓度与分指数。

| 项目 | 说明 |
|------|------|
| 覆盖范围 | 中国大陆主要城市 |
| 更新频率 | 约每小时更新 |
| 时区 | 业务时间多为北京时间；场站预报库内为 UTC，响应同时提供本地时间 |
| 鉴权 | 请求头 `X-API-Key`；需开通对应模块权限 |

### 相关参考

- [城市列表](/zh/reference/location-codes)

## 请求

```
GET /v1/aqi/condition
GET /aqi/condition
```

### 查询参数

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `city_uid` | integer | 四选一 | 内部城市 ID，优先级最高 |
| `city_code` | string | 四选一 | GB2260 行政区划代码，如 `110000` |
| `city_name` | string | 四选一 | 城市名称，如 `北京市` |
| `lat` | number | 与 lon 成对 | 纬度 -90~90 |
| `lon` | number | 与 lat 成对 | 经度 -180~180 |
| `format` | string | 否 | 响应格式：`json`（默认）/`csv`/`tsv`/`xml`/`yaml` |

## 响应

结构：`{ city, condition }`。

### `condition` 字段

| 字段英文名 | 类型 | 单位 | 中文名 |
|------------|------|------|--------|
| `update_time` | string | ISO8601 | 更新时间 |
| `aqi` | number | — | 空气质量指数 |
| `aqi_level` | number | 1–6 | 等级编号 |
| `aqi_level_name` | string | — | 等级名称（优/良/轻度污染…） |
| `pm25` | number | μg/m³ | PM2.5 |
| `pm10` | number | μg/m³ | PM10 |
| `so2` | number | μg/m³ | 二氧化硫 |
| `no2` | number | μg/m³ | 二氧化氮 |
| `o3` | number | μg/m³ | 臭氧 |
| `co` | number | mg/m³ | 一氧化碳 |
| `pm25_iaqi` | number | — | PM2.5 分指数 |
| `pm10_iaqi` | number | — | PM10 分指数 |
| `so2_iaqi` | number | — | SO₂ 分指数 |
| `no2_iaqi` | number | — | NO₂ 分指数 |
| `o3_iaqi` | number | — | O₃ 分指数 |
| `co_iaqi` | number | — | CO 分指数 |
| `primary_pollutant` | string | — | 首要污染物 |
