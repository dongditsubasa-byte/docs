## Request headers

```http
GET /v1/weather/condition?city_name=Beijing HTTP/1.1
Host: api.sunnymeteo.com
X-API-Key: your_api_key_here
Accept: application/json
```

## Module grants

Access is granted **per module**. Unauthorized modules return `403`. Common modules:

| Module code | Endpoints |
|-------------|-----------|
| `condition` | `/weather/condition` |
| `24hourly` / `360hourly` | Hourly forecasts |
| `15daily` / `life_index` | 15-day / life index |
| `aqi` / `aqi_hourly` | Air quality |
| `power_*` | Station APIs |
| `earthquake_*` / `typhoon_*` | Disaster APIs |
| `global_alerts` / `meteo_alerts` / `all_alerts` | Alerts |

## Rate limits

- Gateway: ~10 req/s per IP (burst 20)
- Application: optional per-user / per-module quotas

Exceeding limits returns HTTP `429`. See [Status codes](/en/reference/status-codes).
