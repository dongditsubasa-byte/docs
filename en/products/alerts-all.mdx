## Overview

Pull incremental nationwide disaster alerts by Unix timestamp (Alert / Cancel / Update).

| Item | Details |
|------|---------|
| Coverage | Mainland China; ~1-day history window |
| Update frequency | About every 30 minutes |
| Timezone | Business times are usually Beijing time; station forecast store uses UTC and responses also include local time |
| Auth | `X-API-Key` header; module grant required |

### Related

- [City list](/en/reference/location-codes)

## Request

```
GET /v1/weather/alerts/all
GET /weather/alerts/all
```

### Query parameters

| Parameter | Type | Required | Description |
|-----------|------|----------|-------------|
| `start` | integer | **yes** | Unix timestamp (seconds); earliest ~1 day ago |
| `city_uid` / `city_code` / `city_name` / `lat`+`lon` | — | no | Optional city filter |
| `format` | string | no | Response format |
