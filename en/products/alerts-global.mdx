## Overview

Returns overseas weather alerts near a country or lat/lon point (upcoming / active; expired excluded).

| Item | Details |
|------|---------|
| Coverage | Selected countries worldwide (by country code or coordinates) |
| Update frequency | About hourly |
| Timezone | Business times are usually Beijing time; station forecast store uses UTC and responses also include local time |
| Auth | `X-API-Key` header; module grant required |

### Related

- [Status codes](/en/api-guide#status-codes--errors)

## Request

```
GET /v1/weather/alerts/global
GET /weather/alerts/global
```

### Query parameters

| Parameter | Type | Required | Description |
|-----------|------|----------|-------------|
| `country_code` | string | XOR with coords | Country code, e.g. `us`, `jp` |
| `lat` | number | with lon | Latitude |
| `lon` | number | with lat | Longitude |
| `format` | string | no | Response format |

Do **not** combine `country_code` with `lat`/`lon`.
