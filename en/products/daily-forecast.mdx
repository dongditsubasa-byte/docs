## Overview

Returns about 15 days of daily forecast including day/night weather, temperature, wind, and precipitation probability.

| Item | Details |
|------|---------|
| Coverage | Major cities in mainland China |
| Update frequency | Several times per day |
| Timezone | Business times are usually Beijing time; station forecast store uses UTC and responses also include local time |
| Auth | `X-API-Key` header; module grant required |

### Related

- [Weather codes](/en/reference/weather-codes)
- [Wind scale](/en/reference/wind-scale)

## Request

```
GET /v1/weather/15daily
GET /weather/15daily
```

### Query parameters

| Parameter | Type | Required | Description |
|-----------|------|----------|-------------|
| `city_uid` | integer | one of four | Internal city ID (highest priority) |
| `city_code` | string | one of four | GB2260 admin code, e.g. `110000` |
| `city_name` | string | one of four | City name, e.g. `Beijing` |
| `lat` | number | with lon | Latitude -90~90 |
| `lon` | number | with lat | Longitude -180~180 |
| `format` | string | no | Response format: `json` (default) / `csv` / `tsv` / `xml` / `yaml` |

## Response

### JSON shape

```json
{
  "city": { "city_code": "440100", "city_name": "广州市" },
  "daily": {
    "update_time": "2026-08-24T07:30:00+08:00",
    "daily": [
      {
        "forecast_date": "2026-08-24",
        "weather_code_day": 2,
        "weather_cn_day": "多云",
        "weather_code_night": 1,
        "weather_cn_night": "晴",
        "temp_min": 26,
        "temp_max": 33,
        "pop_day": 20
      }
    ]
  }
}
```

| `weather_code_night` | integer | — | Nighttime weather code |

| `temp_min` | number | ℃ | Min temperature |
| `temp_max` | number | ℃ | Max temperature |

| `wind_level_night` | number | Beaufort | Nighttime wind force |
| `pressure_day` | number | hPa | Daytime pressure |
| `pressure_night` | number | hPa | Nighttime pressure |

| `mslp_night` | number | hPa | Nighttime MSLP |
| `humidity_day` | number | % | Daytime relative humidity |
| `humidity_night` | number | % | Nighttime relative humidity |
