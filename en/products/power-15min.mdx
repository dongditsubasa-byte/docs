## Overview

Linearly interpolates the hourly forecast to 15 minutes; weather codes follow the parent forecast hour. Alias path: `/power/minutely`.

| Item | Details |
|------|---------|
| Coverage | Active PV / wind stations |
| Update frequency | Follows hourly forecast batches (06:00 / 19:00 Beijing time) |
| Timezone | Business times are usually Beijing time; station forecast store uses UTC and responses also include local time |
| Auth | `X-API-Key` header; module grant required |

### Related

- [Hourly forecast](/en/products/power-hourly)
- [Weather codes](/en/reference/weather-codes)

## Request

```
GET /v1/power/15min
GET /power/15min
GET /v1/power/minutely   # compatibility alias
```

### Query parameters

| Parameter | Type | Required | Description |
|-----------|------|----------|-------------|
| `station_alias` | string | one of three | Internal station alias (preferred), e.g. `PVSDCW` |
| `station_name` | string | one of three | Station name |
| `lat` | number | with lon | Latitude; nearest active station |
| `lon` | number | with lat | Longitude |
| `format` | string | no | `json`/`csv`/`tsv`/`xml`/`yaml` |
