API fields `weather_code` / `weather_cn` (station APIs also expose `weather_text`) use the standard codes below.

Download the full table: `weather_codes` sheet in [china_cities.xlsx](/files/china_cities.xlsx), or [weather_codes.csv](/files/weather_codes.csv).
